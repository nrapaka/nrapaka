# Hi, I'm Narsimha Reddy Rapaka 👋

**Research Scientist at Khalifa University of Science and Technology, Abu Dhabi**

I develop numerical methods for fluid dynamics: fast solvers for elliptic and
nonlinear PDEs, embedded-boundary and immersed-boundary methods for complex
geometry, and, more recently, quantum-inspired tensor-network algorithms that
compress whole simulations into low-rank tensor trains.

### 🔬 Research interests

- **Quantum-inspired algorithms**: tensor-train (QTT) solvers, all-at-once space–time methods, multilevel preconditioning, tensor-train dynamic mode decomposition
- **Computational fluid dynamics**: DNS, LES and RANS of turbulent and stratified flows; wall-modelled LES
- **Complex geometry**: embedded- and immersed-boundary methods, ghost-cell reconstruction, adaptive mesh refinement
- **Fast solvers and numerical analysis**: multigrid, fast multipole methods, spectral methods for non-periodic domains, non-normal stability and ε-pseudospectra
- **High-performance computing** for large-scale simulation

### 🛠️ Current work

- **QCFD**: an incompressible Navier–Stokes solver in quantized tensor-train format, with RANS and LES turbulence models, a wall model and a graphical front end (repository currently private)
- Quantum-inspired multilevel tensor-train space–time solvers for nonlinear PDEs
- Tensor-train dynamic mode decomposition for large-scale non-stationary flows
